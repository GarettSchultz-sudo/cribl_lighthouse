Connected feeds

Live endpoints this prototype is modeled on (verified June 2026).

FedRAMP RSS feeds send no CORS headers, so the browser can't read them directly. The backend polls them server-side and re-serves them at /feeds with CORS — set CONTROLS_API and these two switch from "via backend" to live. No public proxy involved. Federal Register & GitHub APIs are CORS-enabled and key-free.
