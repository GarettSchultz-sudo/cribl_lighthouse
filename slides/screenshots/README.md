## Capture tips (macOS)

- **Cmd-Shift-4**, then **space**, then click the browser window — clean window grab with shadow.
- Hide the bookmarks bar (Cmd-Shift-B) and close devtools for a cleaner shot.
- Target size: **1600×1000** or wider. The deck scales them; don't capture at retina-doubled size if it'll exceed 3 MB.
